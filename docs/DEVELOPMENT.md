# 開発メモ

## 動かす

```bash
npm start      # http://localhost:8080（依存パッケージなしの静的サーバー）
npm run check  # 全 JS の構文チェック
npm test       # Playwright で通し動作テスト（下記）
npm run icons  # icons/*.png を再生成
```

`npm test` は Playwright を使います。グローバルに入っている場合は

```bash
mkdir -p node_modules && ln -s "$(npm root -g)/playwright" node_modules/playwright
```

でリンクするか、`npm i -D playwright` を入れてください。

## テストが見ているもの

`scripts/smoke.mjs` は実ブラウザで以下を通します。

1. 生成した JPEG 5 枚を `importFiles()` に通し、EXIF / 更新日時から `2024年5月` に振り分くこと
2. `autoSlot()` が 5 枚を 1 コマにまとめ、6 分割レイアウトを選び、サムネイルを作ること
3. 年表 → コマ編集の遷移、レイアウト変更、自動配置で 3 マスが埋まること
4. キャンバスが白紙でないこと
5. 書き出しが **600 × 800**（instax mini Link のネイティブ解像度）であること
6. A4 シートのタイルが **46×62mm**、カードモードで **54×86mm ＋ 白フチ欄**になること
7. **印刷時**の `.page` が padding 0・幅 194mm・高さ 281mm 以内であること
8. テプラ用ラベルに年月・出来事・補足が出ること
9. コンソールエラーが 1 件も出ていないこと

**7 が一番壊れやすい箇所です。** A4（210×297mm）から `@page` の余白 8mm を引いた
194×281mm が組版の前提で、`js/output.js` の詰め込み計算と CSS の flex 折り返しが
同じ幅を見ている必要があります。ここがずれると、画面では 4 列なのに紙では 3 列になり、
`.page` 1 枚が物理 2 ページに割れます。

## 設計メモ

### レンダリングは 1 箇所だけ

`js/render.js` の `renderFrame(ctx, frame, imgs, W, H)` が唯一の描画コードで、
プレビュー・一覧サムネ・instax 書き出し・A4 シートがすべてこれを呼びます。
座標はすべてフレームサイズに対する相対値なので、出力解像度を変えても見た目が変わりません。
**描画に関する変更は必ずここに入れてください。**

### 写真の持ち方

| | 用途 | サイズ |
|---|---|---|
| `blob` | 編集・印刷 | 長辺 2048px に縮小した JPEG |
| `thumb` | 一覧・トレイ | 長辺 320px |

元ファイルは保持しません（容量のため）。2048px あれば 600×800 のコマに
6 倍ズームしても足ります。デコード済み `ImageBitmap` は `js/photos.js` の
`bitmaps` Map にキャッシュされます。

### はみ出し防止

`js/editor.js` の `clampCell()` が、回転後のバウンディングボックスから
パン量の上限を計算して写真がセルを必ず覆うようにしています。
レイアウト・向き・分割位置・ズームを変えたあとは必ず呼んでください
（`rects` が更新されてから呼ぶ必要があるので、`draw()` → `clampCell()` → `draw()` の順です）。

### 保存

編集操作は 350ms のデバウンス後に IndexedDB へ書き込みます。
画面を離れる・タブを隠す・コマを移動するときは `flushSave()` で確定させます。
保存のたびに一覧用サムネイルも作り直します。

## 追加するとしたら

- 1 ヶ月に複数コマ（データ構造の `idx` は既に用意済み。UI と年表の複数行表示が必要）
- コマの並べ替え／別の月へ移動
- 手動での年月指定（EXIF が無い・間違っている写真向け）
- テンプレートのプリセット保存（毎回同じ余白・背景にしたい場合）
