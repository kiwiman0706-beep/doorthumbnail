# 印刷まわりの実情 — instax mini Link / テプラ / PWA と APK

「PWA から instax mini Link とテプラに直接つなげたい」への回答と、
実際に選べる手段の整理です。

---

## 1. 結論（先に）

| やりたいこと | PWA（このアプリ） | ネイティブ APK にした場合 |
|---|---|---|
| 写真の選択・トリミング・合成・年表管理 | ✅ できる | ✅ できる（作り直しが必要） |
| インクジェットで A4 に等倍印刷 | ✅ できる | ✅ できる |
| instax mini Link で印刷 | ⚠️ **純正アプリへ「共有」して印刷**（ワンタップ挟まる） | ⚠️ 直接印刷は非公式実装か、富士フイルムとの個別契約が必要 |
| テプラで印刷 | ⚠️ **CSV／コピペ**で純正アプリ・PC ソフトへ渡す | ⚠️ 対応機種＋キングジムへの SDK 利用申請が必要 |

**おすすめ：PWA のままで運用する。**
直接印刷のために APK 化しても、下で説明する理由から得られるものが小さく、
壊れやすい（メーカー側のアプリ更新で動かなくなる）実装を抱えることになります。

---

## 2. instax mini Link

### なぜ PWA から直接印刷できないのか

1. **プロトコルが非公開**
   instax mini Link はスマホと Bluetooth で通信しますが、その通信内容（コマンド仕様）を
   富士フイルムは一般公開していません。純正アプリだけが正式な送信手段です。
2. **Web Bluetooth の制約**
   仮に仕様がわかっても、Web Bluetooth が使えるのは Chrome / Edge 系（Android・Windows・macOS・ChromeOS）だけで、
   **iOS の Safari では使えません**。iPhone / iPad では原理的に不可能です。

> コミュニティによる解析プロジェクト（Mini Link 2 などを対象にした非公式実装）は存在しますが、
> 機種・ファームウェアに強く依存し、メーカー保証の対象外です。
> 業務利用向けに富士フイルムが SDK を提供している場合もあるため、
> どうしても直接印刷したい場合は富士フイルムへ直接問い合わせるのが唯一の正規ルートです。

### このアプリでの実際のながれ（推奨）

```
コマを編集 → 「出力」タブ →「共有」→ instax mini Link アプリを選ぶ → そのまま印刷
```

- 書き出し解像度は **600 × 800 px**（ヨコ向きは 800 × 600）。
  これは instax mini Link がフィルムの画像部 46 × 62mm に印刷する際の実解像度と同じです。
- **instax アプリ側で拡大・トリミングし直さないでください。** せっかく合わせた構図がずれます。
  このアプリが出す画像はすでにフィルムの縦横比ちょうどなので、触らず印刷するのが正解です。
- 「共有」が出ない環境（PC の Chrome など）では自動的にファイル保存に切り替わります。

### Android なら逆向きの連携も使えます

このアプリは **Web Share Target** に対応しています。
ホーム画面に追加しておくと、ギャラリーで写真を複数選んで「共有」→「ドア年表」を選ぶだけで
取り込み＋年月ごとの自動配置まで走ります。

> 注意：共有経由で受け取った写真にはファイルの更新日時が付きません。
> EXIF の撮影日があればそこから年月を判定しますが、EXIF が無い画像は「今日」の月に入ります。

## 3. テプラ（キングジム）

### なぜ PWA から直接印刷できないのか

- テプラのスマホ対応機は、Bluetooth で**純正アプリ専用**の通信をしています。
  ブラウザからその通信を行う手段はありません（ここでも Web Bluetooth は iOS 非対応）。
- キングジムは一部の**業務向け機種**（SR5900P、SR-R シリーズなど）に限って
  開発者向け SDK を提供しています。ただし
  - **利用にはキングジムへの申請・契約が必要**
  - **ネイティブアプリ（iOS / Android / Windows）専用** で、ブラウザからは使えない
  - **家庭向けの機種は対象外**のことが多い

  ——ので、「手持ちのテプラが何であれ APK にすれば直結できる」わけではありません。
  まず **お使いの機種が SDK 対応かどうか**を確認するのが先です。

### このアプリでの実際のながれ（推奨）

**印刷 / ラベル → テプラ用ラベル** で、対象のコマぶんの文字列をまとめて作ります。

- **PC で刷る場合（速い・おすすめ）**
  CSV（BOM 付き UTF-8）を書き出して、テプラの PC ソフト（SPC10 など）の
  **差し込み印刷**に読み込ませると、何十枚ぶんでも一気に刷れます。
  列は `年 / 月 / 年月 / 1行目 / 2行目` です。
- **スマホだけで刷る場合**
  「コピー」してテプラアプリの入力欄に貼り付けます。
  1 行に `年月 <TAB> 補足` の形で出るので、必要な行だけ貼れば OK です。
- **そもそもテプラを使わない選択肢**
  インクジェット印刷を **「カード全体 54×86mm」＋「カード下の白フチに出来事を印刷する」** にすると、
  白フチに年月と出来事が最初から刷り込まれた状態で出てきます。
  instax 実物の質感は出ませんが、**ラベル貼りの工程がまるごと消えます。**

## 4. APK 化について

### 4-1. TWA（このアプリをそのまま APK で包む）

[Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) を使えば、この PWA を
数分で Play ストア配布可能な APK / AAB にできます。

```bash
npm i -g @bubblewrap/cli
bubblewrap init --manifest https://<公開URL>/manifest.webmanifest
bubblewrap build
```

ただし **中身は Chrome** なので、**できることは PWA と完全に同じ**です。
instax にもテプラにも直結できるようにはなりません。
ホーム画面アイコンと共有先としての見た目が少し良くなるだけです。

### 4-2. 本格的なネイティブアプリ（Flutter / Kotlin）に作り直す

直結を目指すなら、この選択肢しかありません。得られるもの・必要なもの：

| | 得られるもの | 必要なもの / リスク |
|---|---|---|
| テプラ | 対応機種なら **アプリ内から直接ラベル印刷** | キングジムへの SDK 利用申請。機種が対象外なら不可能 |
| instax | 非公式プロトコルでの直接印刷 | 解析実装の移植。機種・ファームウェア依存で**ある日動かなくなる**。正規ルートは富士フイルムとの個別交渉 |
| 共通 | — | UI をゼロから作り直し。iOS は別途ビルドと Apple の年 $99 |

### 4-3. 判断のめやす

- **まずは PWA のまま運用してみる。** 月の作業は「取り込み → 数コマ微調整 → 共有 or A4 印刷 → ラベル CSV」で、
  ボトルネックだった「複数写真を 1 枚に収める」はもう自動化されています。
- 運用してみて **テプラのラベル貼りが一番の苦痛** だとわかったら、
  まず「カード全体＋白フチ印刷」でテプラ自体をやめられないか試す。
- それでもテプラが必要で、かつ **手持ちが SDK 対応機種**だったときに初めて、
  ネイティブ化を検討する価値が出ます。

## 5. 実寸メモ（自作・改造するとき用）

| | 値 |
|---|---|
| instax mini カード全体 | 54 × 86 mm |
| instax mini 画像部 | 46 × 62 mm |
| instax mini Link 印刷解像度 | 600 × 800 dots（約 12.5 dots/mm） |
| 白フチ（タテ置き） | 上 5mm / 左右 4mm / 下 19mm |
| A4 に並ぶ枚数（余白 8mm・間隔 3mm） | 画像部のみ：4 × 4 = **16 枚/ページ**<br>カード全体：3 × 3 = **9 枚/ページ** |

これらは `js/model.js` の `INSTAX` 定数と `js/output.js` の組版に入っています。
