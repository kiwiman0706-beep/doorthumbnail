# TEPRA native library placement

After accepting KING JIM's SDK license, place the native libraries as follows:

```text
arm64-v8a/libTepraPrint.so
armeabi-v7a/libTepraPrint.so
x86/libTepraPrint.so
x86_64/libTepraPrint.so
```

The `.so` files are intentionally ignored by Git and are not included in source archives.
